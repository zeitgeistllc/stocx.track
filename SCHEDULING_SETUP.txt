# SCHEDULING SETUP (Run Daily at 17:00 UTC)

## OPTION 1: Linux/Mac (Cron)
================================================================================
Edit crontab:
  crontab -e

Add this line (17:00 UTC = 5:00 PM):
  0 17 * * * cd /path/to/project && /usr/bin/python3 daily_pnl_automation.py >> daily_pnl.log 2>&1

Verify:
  crontab -l


## OPTION 2: Windows (Task Scheduler)
================================================================================
1. Open Task Scheduler
2. Create Basic Task:
   - Name: "Daily PnL Tracking"
   - Trigger: Daily, 17:00 UTC
   - Action: Start a program
     Program: C:\Python\python.exe
     Arguments: daily_pnl_automation.py
     Start in: C:\Users\YourUser\daily_pnl_project\

3. Advanced:
   - Run with highest privileges
   - Run only when user is logged in
   - Run whether user is logged in or not (if you want background execution)


## OPTION 3: Python APScheduler (Cross-platform)
================================================================================
Install: pip install apscheduler

Create scheduler.py:

```python
from apscheduler.schedulers.background import BackgroundScheduler
from daily_pnl_automation import main
import logging

scheduler = BackgroundScheduler()

# Schedule job for 17:00 UTC daily
scheduler.add_job(
    func=main,
    trigger="cron",
    hour=17,
    minute=0,
    timezone='UTC',
    id='daily_pnl_job'
)

scheduler.start()

try:
    while True:
        time.sleep(1)
except KeyboardInterrupt:
    scheduler.shutdown()
```

Run:
  python scheduler.py
